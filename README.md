# Boxes App

This project is a beginner-level React application built as part of a React learning assignment.  
It demonstrates the use of functional components, props, and basic CSS styling.

## Project Description

The Boxes App displays three boxes labeled **Small**, **Medium**, and **Large**, styled using CSS.  
The layout and colors follow the provided design specifications.

## Concepts Used

- React Functional Components
- Props
- JSX
- CSS Styling
- Project setup using Create React App

## Design Reference

The UI is implemented based on the following design guidelines:
- Responsive box layout
- Consistent colors and typography
- Clear visual hierarchy
